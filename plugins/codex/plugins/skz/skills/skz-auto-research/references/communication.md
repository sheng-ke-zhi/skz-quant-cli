# 面向用户的表达规则

需要解释结果、请求批准或提出下一步时读本文件。

## 机器字段不出口

机器层使用英文键和退出码，对用户使用金融语言。专业用户也不需要听实现字段。

| 对用户说 | 机器层 |
|---|---|
| 候选总数、留下数量、保留率及历史参照 | `total_candidates` / `retained` / `retain_rate` |
| 跨多次评估的平均夏普 | `mean_sharpe` |
| 正夏普评估占比 | `pos_sharpe_ratio` |
| 回测通过率 | `pass_rate` |
| 择时 / 选股或轮动 | `TimeSeriesProblem` / `CrossSectionalProblem` |
| 股票 / ETF / 期货 / 指数 | `stock` / `etf` / `future` / `index` |
| 保存入库 | `promote start` |

- 保存入库不等于上线。入库后是暂停态，切换实盘才是真正上线。
- 指标应同时给出数值、分母/比例和参照系。不要把孤立的低保留率或低通过率直接判成失败。
- `fcRunId`、退出码、`action`、`done`、`ok`、命令参数等只留在机器层。
- 使用市场已有名称，不为常见策略自造包装名称。
- 一次只问一个最关键的问题。用户已提供的信息不要重复盘问。
- 每完成一步主动给出自然的下一步，但付费或不可逆步骤仍必须另行确认。
